# CLAUDE.md

このファイルは、このリポジトリで作業する際にClaude Code (claude.ai/code) へ向けたガイドを提供する。

## コマンド

- `npm run dev` — HTTPサーバー起動（`src/server.js`）。`PORT`環境変数未指定時は3000番ポート
- `npm test` — 全テスト実行（`node --test`、`test/`配下を自動検出）
- `node --test test/memo.test.js` — 単一テストファイルのみ実行

## アーキテクチャ

ESMプロジェクト（package.jsonの`"type": "module"`）。外部依存なし、Node標準機能のみ使用。

- `src/memo.js` — インメモリのデータ層。全状態（`memos`配列・`nextId`カウンタ）を保持し、`listMemos`/`addMemo`/`deleteMemo`/`resetMemos`を公開する。状態を持つのはここだけ。`resetMemos`はテスト間の状態リークを防ぐためだけに存在する
- `src/server.js` — `node:http`のみで構成した薄いHTTP層（フレームワーク不使用）。method/URLでルーティングし、`memo.js`の関数をそのまま呼び出してJSONで返すだけ。新規エンドポイントは既存の`/memos`ルートと同じパターンマッチ方式で追加する
- `test/` — `node:test`のテストファイル。各テストの冒頭で`resetMemos()`を呼びテスト間の状態リークを防ぐ

## 禁止事項

- `.env` や秘密情報を含むファイルを不用意に表示しないでください。
- APIキー、トークン、パスワードをコード内に直書きしないでください。
- マジックナンバーを使用しないでください。
- ユーザーの明示承認なしに本番環境向けの変更を行わないでください。
- 不要な大規模リファクタリングを行わないでください。

## 「新しい発見」の扱い

あなたやサブエージェントが「新しい発見」をしたとき、その多くは次のいずれかであることを肝に銘じてください。

- 意図された実装（設計意図がコメントや別レイヤーに書かれている）
- 計測・計算ミス（標本が小さい、単位や順序が違う）
- 錯覚（ノイズを傾向として読む、相関を因果と読む）
- 局所のみで判断（関数単体で正しさを論じ、呼び出し側を見ていない）
- 計器の側の誤り（測っている量が、その名前が指す量と違う）

上記をクリアした場合のみ、有用な可能性があると扱われます。

## 作業完了時の報告形式

作業完了時は以下の形式で報告してください。

1. 実施内容
2. 変更ファイル
3. 動作確認結果
4. 残課題
5. 次にやるべきこと
