アナライザで強制にする — 「入れた」は「効いている」ではない

「金額に double・float を使わない」「端数処理は Money の中だけ」を、お願いからビルドで止める強制に変えた。最新版のアナライザが黙って無効になること、型の宣言とキャストは検査されないことを実測で見つけ、両方に手当てをした。

2026-10-05対象: sales-core ／ src 配下の全プロジェクト段階1 / Day23

エグゼクティブサマリー

  1. 違反コードでビルドが落ちるようになった。違反を1種類ずつ入れた8ケースはすべて失敗し、違反なしは成功した。CLAUDE.md の2行は「お願い」から「強制（ビルド）＋お願い」に変わった。
  2. 最新版のアナライザ（5.6.0）は、警告1件を出すだけで何も検査していなかった。SDK のコンパイラより新しく、読み込まれない。3.3.4 に固定し、その警告（CS9057）をエラーにした。
  3. BannedApiAnalyzers は型の宣言とキャストを見ない。double・float はソースの文字列の検査で止め、Money.cs 以外での抑止もビルドで止めた。
  4. 止められない書き方が2つ残る（var x = 1.5、(long)amount）。実測したうえで、レビューで拾うと明記した。

01違反22箇所を、構成ごとにビルドした

アナライザを入れても、版が合わなければ何も止まらない。止めたいものを入れて、止まるのを見るまで分からない。

5.6.0 の CS9057 は「アナライザがコンパイラ 4.12 を参照している。実行中は 4.11」という知らせ。SDK 8.0.421 より新しいアナライザは読み込まれず、違反22箇所のままビルドが通った。警告は1件だけで、ほかの出力に紛れる。手当ては、3.3.4 に固定することと、CS9057 をエラーにすること（5.6.0 で失敗することを確認）。

02道具が見ないところを、別の検査で止める

BannedApiAnalyzers は API の呼び出しを見る道具で、型の宣言とキャストは見ない。そこをソースの文字列の検査で補った。

図表2: 3つの止め方と、その範囲
コード仕組み止めるもの
RS0030BannedApiAnalyzers 3.3.4（src/BannedSymbols.txt）Math.Round・decimal.Round の全形、Floor・Ceiling・Truncate、Convert.ToInt32/64
SALES001コンパイル前に、ソースの文字列を調べるdouble・float の宣言とキャスト
SALES002同上Money.cs 以外での RS0030 の抑止（#pragma・SuppressMessage・NoWarn）
CS9057エラーに格上げアナライザが読み込まれずに黙って無効になること

SALES002 は計画に無かったが、「強制」と書くための前提として足した。抑止が自由なら、エラーが出た人が1行足して黙らせられる。抑止してよいのは Money.cs の丸めと正規化の2箇所だけ。

既存のコードも6箇所が引っかかった。Money.cs の3箇所は2箇所を #pragma で許可し、1箇所は書き換えた。TaxRate.cs・SalesOrderLine.cs の桁数の検査（小数2桁・3桁まで）は、decimal.Truncate を x * 100m % 1m != 0m に替えた。端数処理ではないが、Truncate を許すと抜け道になるため。

05今日学んだこと

安全柵は、止まるべきものを入れて、止まるのを見るまで効いているとは言えない。

  • 「入れた」は「効いている」ではない。最新版を入れた時点でビルドは通り、警告は1件だった。違反を入れて確かめなければ「強制にした」と記録していた。Day17 の dev-guard と同じ教訓を、ビルドの設定でも繰り返した
  • 安全柵が外れたことを知らせる警告は、エラーにする。CS9057 は「この道具は今動いていない」という知らせだった
  • 道具が何を見ていて、何を見ていないかを測る。名前から「禁止したものは全部止まる」と思い込んでいた。違反を種類ごとに並べたことで、止まらない5箇所がはっきりした
  • 強制には、抜け道を塞ぐところまで含める。1行で黙らせられるなら強制ではない
  • 止められない穴は、穴として書く。「強制」と書くなら、どこまでが強制かも書く

つまずき

  • 対照実験の書き戻しで、csproj の先頭の BOM が外れた。文字列として読み、BOM なしで書き戻したため。git で元に戻し、スクリプトをバイト列のまま退避・復元する形に直した。直した版でもう一度実行し、差分が出ないことを確かめた

CS9057 の全文（5.6.0 のとき）:

CSC : warning CS9057: アナライザー アセンブリ '…\bannedapianalyzers\5.6.0\…BannedApiAnalyzers.dll' は、
コンパイラのバージョン '4.12.0.0' を参照しています。これは、現在実行中のバージョン '4.11.0.0' よりも新しいバージョンです。

ビルドで止める設定（src/Directory.Build.props の要点）:

<PackageReference Include="Microsoft.CodeAnalysis.BannedApiAnalyzers" Version="3.3.4" PrivateAssets="all" />
<AdditionalFiles Include="$(MSBuildThisFileDirectory)BannedSymbols.txt" />
<WarningsAsErrors>$(WarningsAsErrors);RS0030;CS9057</WarningsAsErrors>

コンパイルの前に（Target BeforeTargets="CoreCompile"）:
  SALES001  ソースが '\b(double|float|Double)\b|\bSystem\.Single\b' に一致する
  SALES002  Money.cs 以外のソースが 'RS0030' を含む ／ NoWarn に RS0030 か CS9057 がある
