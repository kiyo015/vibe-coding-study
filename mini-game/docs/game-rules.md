# ゲーム仕様

数当てゲーム。プレイヤーは隠された整数を推測する。

- 出題範囲: `MIN_NUMBER`(1) 〜 `MAX_NUMBER`(500)
- 試行回数の上限: `MAX_TRIES`(10回)。二分探索なら最悪9回(`ceil(log2(500))`)で当たるため、1回分の余裕を持たせた値。中央以外から入るプレイヤーに猶予を残しつつ、探索空間は1〜100時代の5倍になっている
- 推測ごとの応答:
  - `low` — 答えはもっと大きい
  - `high` — 答えはもっと小さい
  - `correct` — 的中。ゲーム終了
  - `lose` — 上限回数に到達。答えを開示してゲーム終了
- 終了後（`finished: true`）にさらに推測すると例外を投げる。UI側で入力欄を無効化する前提だが、ロジック側でも防御する

## 調整する時の注意

`MAX_TRIES`を変えるとゲームの難易度が根本的に変わる。二分探索での最悪手数は`ceil(log2(MAX_NUMBER - MIN_NUMBER + 1))`なので、範囲を広げる場合は上限回数も合わせて見直すこと。
